# 表达助手 - 微信小程序设计文档

> 日期：2026-07-23
> 状态：设计已完成，待制定实现计划

## 一、产品定位

一个以**长期表达能力成长**为核心、同时兼顾即时辅助的微信小程序。核心差异化：不替用户想，而是帮用户**说出自己心里有但说不清的话**。

### 与"AI帮我写"的本质区别

| 维度 | AI帮我写 | 本产品 |
|------|---------|--------|
| 输入 | 只输入问题 | 输入对方观点 + 自己碎片想法 |
| 输出 | 一句话回复 | 多风格表达 + 保真度溯源 + 技巧拆解 + 对方反击预测 |
| 定位 | 替你想 | 帮你说 |
| 长期价值 | 无，用后即走 | 积累表达模板 + 训练表达能力 |

---

## 二、目标用户

覆盖全人群，从大学生到职场资深人士。核心诉求：在对话中被"噎住"后，能把脑子里模糊的想法组织成有力表达。

---

## 三、核心场景

所有生活/工作场景覆盖，预设 + 搜索：

- **预设场景**：工作会议、朋友争论、家庭沟通、面试准备、饭局社交、向上沟通、亲密关系、公开演讲等
- **搜索补充**：用户可搜索特定场景，数据积累后扩展预设库

三种使用时机：
- **即时辅助**（在线聊天）：快速生成表达应对
- **事后复盘**（与熟人争论后）：记录问题，回来生成，下次用
- **提前准备**（面试、饭局等）：预判问题，提前生成表达储备

## 四、产品架构

### 三个主Tab

| Tab | 内容 |
|-----|------|
| 场景广场（首页） | 场景卡片网格 + 顶部搜索框 + 最近使用 |
| 训练场 | 模拟对战 + 技能拆解 + 历史笔记 |
| 我的 | 成长数据 + 收藏 + 设置 |

### 核心交互流

```
场景广场 → 点击场景 → 场景工作区（生成页）
                        ├── 生成表达 → 结果页（多风格 + 溯源 + 技巧 + 对话链预测）
                        ├── 进入模拟对战 → 沉浸式多轮对抗
                        └── 查看历史笔记
```

生成页与模拟对战分页独立，避免拥挤，每个功能有完整沉浸空间。

## 五、页面设计

### 5.1 场景工作区（生成页）

两个输入框上下排列：
- **输入框1**："对方说了什么？把你不同意的那句话写进来..."
- **输入框2**："你的想法（乱一点也没关系），把脑子里碎片倒出来..." + 🎤语音按钮
- 主按钮：「生成表达」，点击后动画过渡 → 跳转结果页
- 底部入口：🥊 进入模拟对战 | 📖 查看历史笔记

### 5.2 生成结果页（核心差异化）

```
📌 对方观点回顾

💭 你的碎片想法回顾

▼ 风格切换：[逻辑拆解] [幽默化解] [反问引导] [情感共鸣]

📝 生成表达（主体内容）

🔍 表达解析：
  ✓ 来自你"XXX想法"的部分
  ✦ AI补充的事实/数据
  💡 表达技巧拆解：用了什么说服方法、为什么有效

⚡ 对话链预测（1-2轮）：
  对方可能回击 →
  你的应对 →

[ 保存到笔记 ]  [🥊 进入模拟对战 ]
```

### 5.3 模拟对战页

- 聊天气泡式界面，AI对手在左，用户在右
- AI角色：强硬但讲理的对手，不迎合
- 用户可选「生成回应」（输入碎片想法）或「自己手打回应」
- 对战结束后弹出复盘卡片，标注亮点和改进点

### 5.4 训练场

- **模拟对战**：多场景可选，全屏沉浸式
- **技能拆解**：逻辑力、共情力、反驳力、幽默力等维度，教学卡片 + 针对性练习
- **历史笔记**：所有保存的生成结果，按场景归类，支持搜索和标记

## 六、技术架构

- **平台**：微信小程序
- **后端**：自建服务，调用国内大模型 API（DeepSeek / 通义千问 / 豆包等）
- **登录**：微信一键登录（openid）
- **语音输入**：微信原生语音识别接口
- **存储**：用户笔记、训练记录云端存储

### AI Prompt 工程核心

| 能力 | Prompt 要点 |
|------|------------|
| 多风格生成 | 同一输入，不同 system prompt 产出不同风格的表达 |
| 保真度溯源 | 要求模型区分"用户原始想法"和"AI补充"，结构化输出 |
| 强硬对手 | system prompt 设定为批判性思维者，主动寻找逻辑漏洞 |
| 技巧拆解 | 要求模型标注使用了什么表达技巧及其原理 |
| 对话链预测 | 要求模型预测对手的合理反击并生成应对 |
