# 个人公众号内容策略

## 定位

- **方向：** 社会观察与观点（D），涉及社会各个方面
- **风格：** ABCD 混合 — 观点犀利 + 温暖共情 + 数据支撑 + 偶尔幽默
- **读者感受：** 「她好敢说」+「她好懂我」+「她好有料」
- **目标读者：** 追求共鸣的年轻人
- **更新节奏：** 周更或双周更，1500 字左右中长文
- **时间投入：** 每周 3-5 小时

---

## 一、灵感系统

### 第一层：日常输入层（被动接收，碎片时间）

| 渠道 | 看什么 |
|------|--------|
| 微博热搜、知乎热榜、B站热门、抖音热榜 | 不追热点本身，看评论区的情绪——大家在吵什么、气什么、焦虑什么 |
| 《看理想》《人物》《那个NG》《三联生活周刊》《正面连接》《极昼工作室》 | 看角度选择，思考「如果是我会怎么写」 |
| 小宇宙播客：随机波动、忽左忽右、声东击西、不合时宜 | 通勤/做家务时听，话题即选题 |
| 小红书搜索 | 搜「年轻人 + 困惑」「打工 + 吐槽」等组合词，评论区是情绪富矿 |

### 第二层：灵感抽屉（主动捕捉，每周 15 分钟）

在手机备忘录或 Notion 维护三个列表：

1. **现象池** — 日常反常现象（如「中午只吃饭不聊天的同事」）
2. **问题池** — 真实的困惑（如「25 岁该不该去一线城市」）
3. **情绪钩子** — 让你产生强烈情绪的时刻（愤怒/感动/无力），情绪背后藏着观点

每个池子攒够 5-10 条，选题永不枯竭。

### 第三层：观点转化

同一个选题，有洞察和没洞察的区别在于能否填完这句话：

> 「大家都以为 \_\_\_\_，但实际上 \_\_\_\_。」

Claude 帮你做：你扔进来一个现象，Claude 给出 3-5 个不同的「但实际上是……」角度。

---

## 二、每周协作流程（总耗时 3-4 小时）

### 环节 1：选题会（30 分钟）

- 你从灵感抽屉挑 2-3 个选题
- Claude 对每个选题输出「选题卡」：可切的角度、核心观点、读者感受、潜在坑
- 产出：选定 1 个角度 + 一句话核心观点

### 环节 2：搭框架（30 分钟）

- Claude 输出文章骨架：钩子类型 → 展开结构 → 追问方向 → 结尾方式
- 你调整框架，在需要个人故事的位置打草稿
- 产出：定稿大纲

### 环节 3：写初稿（1.5-2 小时）

两种方式可选：
- **写法 A（你写 Claude 改）：** 适合有清晰想法的时候
- **写法 B（Claude 扩写你填充）：** 适合起步阶段，把草稿变成「你的东西」

### 环节 4：打磨定稿（30-40 分钟）

- Claude 生成 10+ 备选标题
- 逐段检查节奏和逻辑
- 开头三秒测试
- 你最终拍板

**核心原则：你做决策，Claude 做体力活。**

---

## 三、文章框架：「钩子 → 展开 → 追问 → 收束」

### 钩子（200 字）
- 场景钩 / 数据钩 / 反常识钩 / 故事钩
- 前三屏留住人

### 展开（800-1000 字）
- 现象→原因→影响
- 正方→反方→我的看法
- 个人的→群体的→时代的

### 追问（200 字）
- 一个读者在心里问过但不敢回答的问题
- 整篇最有观点力的部分

### 收束（200 字）
- 金句收尾 / 回扣开头 / 开放问题
- 不强行升华

---

## 四、Claude 协作方式总结

| 环节 | Claude 的角色 | 你的角色 |
|------|-------------|---------|
| 选题 | 发散角度、预警坑位 | 做选择 |
| 框架 | 输出骨架 | 调整拍板 |
| 初稿 | 扩写草稿/提供素材 | 注入观点、故事、语气 |
| 打磨 | 改废话、起标题、测节奏 | 主编决策 |

**Claude = 灵感引擎 + 编辑助理。你始终是作者。**
